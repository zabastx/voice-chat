# Voice Chat 0.1.0-alpha.1

## Что изменилось

- Появилась постоянная Windows identity Voice Chat и единый экземпляр приложения.
- Добавлены русский per-user NSIS installer и Portable EXE без установки. Оба используют один
  профиль, поэтому Sign-in и настройки не расходятся между вариантами запуска.
- Uninstaller полностью удаляет приложение, общий WebView2 profile, настройки и локальные логи,
  не затрагивая системный WebView2 Runtime.
- Закрытие скрывает окно в трей, а локальный экран помогает восстановить соединение с сервером.
- Release EXE принимает только встроенный HTTPS origin и открывает внешние страницы в браузере.
- Portable EXE проверяет обновления при запуске и каждые шесть часов. Новая версия предлагает
  открыть её точную страницу GitHub Release для ручной замены; «Отложить» ничего не устанавливает.
- Локальные диагностические логи ограничены по размеру и не содержат URL или данные Sign-in.

## Известные ограничения

- Первая private-group alpha не подписана Authenticode, поэтому Windows SmartScreen может показать
  предупреждение.
- Глобальный push-to-talk не реализован.
- Реальные устройства, screen share, сон и пробуждение и длительные звонки требуют ручной проверки.

## Как установить или обновить

Установите `x64-setup.exe` без прав администратора или запустите `x64-portable.exe` напрямую.
Portable хранит данные в профиле Windows, а не рядом с EXE. Он не заменяет себя автоматически:
после согласия скачайте новый Portable EXE со страницы выпуска и замените старый вручную.
