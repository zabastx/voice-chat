# Voice Chat 0.1.0-alpha.2

## Что изменилось

- Проверочный patch-alpha: выпуск подтверждает живой путь обновления с `0.1.0-alpha.1` по
  production Update feed.
- Клиентских изменений относительно `0.1.0-alpha.1` нет: состав shell, Native Bridge и нативных
  возможностей тот же.
- Выпуск проверяет, что installed-клиент сам находит новую версию, ждёт окончания разговора в
  голосовом канале и сохраняет Sign-in после перезапуска, а Portable открывает страницу этого
  выпуска для ручной замены.

## Известные ограничения

- Сборка не подписана Authenticode, поэтому Windows SmartScreen может показать предупреждение.
- Глобальный push-to-talk не реализован.
- Реальные устройства, screen share, сон и пробуждение и длительные звонки требуют ручной проверки.
- Portable EXE не заменяет себя автоматически: после согласия скачайте новый Portable EXE со
  страницы выпуска и замените старый вручную.

## Как установить или обновить

- Installed-клиент предложит обновление при запуске. После согласия он перезапустится уже
  обновлённым и сохранит Sign-in; если идёт разговор в голосовом канале, установка дождётся его
  окончания.
- Portable-клиент предложит открыть страницу этого выпуска в браузере для ручной замены одного
  файла.
- Для первой установки скачайте `x64-setup.exe` без прав администратора или запустите
  `x64-portable.exe` напрямую. Portable хранит данные в профиле Windows, а не рядом с EXE.
